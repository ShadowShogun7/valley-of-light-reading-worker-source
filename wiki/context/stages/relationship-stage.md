# 關係階段判讀

## core

Relationship stage is not astrology evidence by itself. It is the context gate that decides how strongly the reading may speak, which action advice is safe, and whether the user's question should be framed as acute stabilization, low-pressure repair, clarification, or release. Astrology can help organize the right questions, but it cannot predict another person's behavior. (claims: context-relationship-stage-001, context-relationship-stage-002)

For Valley, stage must be deterministic input to the reducer. A cold-war stage should not produce the same answer as a recent breakup, a long separation, a still-together crisis, or an ambiguous not-yet-defined bond. The chart evidence stays the same; the allowed conclusion changes. (claims: context-relationship-stage-001, context-relationship-stage-003)

## in_relationship

When the relationship still exists, stage context should keep the reading focused on pressure, communication, and repair conditions. It should not romanticize conflict as destiny or tell the user to carry repair alone. (claims: context-relationship-stage-003)

## in_breakup

When the relationship is already broken or no-contact, stage context should lower certainty about the other person's internal state and emphasize observable response, timing climate, and whether waiting remains healthy. (claims: context-relationship-stage-001, context-relationship-stage-002)
