# 行星功能三模式模板

## core

George/Bloch 把元素與三模式拆成兩種語法：元素描述能量如何成形，三模式描述能量如何運動。這支持 runtime 把 modality 做成關係節奏矩陣，而不是把星座模板只停在元素或 generic sign description。(claims: western-function-modality-templates-001)

Cardinal 適合說明啟動、外推、先開始；fixed 適合說明維持、集中、抗拒快速改變；mutable 適合說明調整、連結、適應變化。放到 Moon/Mercury/Venus/Mars/Saturn 上時，modality 要回答該功能的反應節奏，不可變成誰比較好或誰一定會回來。(claims: western-function-modality-templates-002, western-function-modality-templates-003, western-function-modality-templates-004)

每個 sign 都是 element + modality 的組合；所以 function-sign runtime 應先把 planet function、element、modality 組合起來，再進入合盤相位與 reducer。這能阻止 Sun-sign-only 或 element-only verdict。(claims: western-function-modality-templates-005)

## in_relationship

關係仍有互動時，三模式矩陣可以翻譯「誰先開口、誰維持、誰轉彎」。Cardinal 不是一定衝動，fixed 不是一定固執，mutable 不是一定不穩；它們只是各自功能的移動方式，仍要看相位與現實互動是否能承接。(claims: western-function-modality-templates-001, western-function-modality-templates-002, western-function-modality-templates-003, western-function-modality-templates-004)

### 優勢

- 能讓 Mars/Saturn 的行動與防衛節奏更精準，不只說某星座性格。(claims: western-function-modality-templates-002, western-function-modality-templates-003, western-function-modality-templates-004)
- 能把冷淡、拖延、變動拆成節奏差異，而不是直接變成責怪。(claims: western-function-modality-templates-001)

### 弱點

- 三模式不能單獨證明對方是否愛、是否逃避、是否會聯絡或是否值得等。(claims: western-function-modality-templates-005)
- 三模式只說 movement pattern；缺少合盤相位與情境時不可輸出行動結論。(claims: western-function-modality-templates-001)

## in_breakup

分手、冷戰或斷聯情境中，modality matrix 用於拆解互動如何卡住：cardinal 可能先推動或先防衛，fixed 可能維持立場或慢慢處理，mutable 可能轉向、分散、或需要更多可調整空間。這些都要寫成條件式機制，不可寫成命運或絕對預言。(claims: western-function-modality-templates-002, western-function-modality-templates-003, western-function-modality-templates-004, western-function-modality-templates-005)
