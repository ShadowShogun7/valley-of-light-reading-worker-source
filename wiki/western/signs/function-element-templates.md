# 行星功能元素模板

## core

George/Bloch 把四元素定義為基本 temperament，並說十二星座由四元素衍生。這支持 Valley 把 element 當成 Moon/Mercury/Venus/Mars/Saturn 的功能修飾層：同一個水象放在 Moon 是安全感接收，放在 Mercury 是語氣與理解，放在 Mars 是衝突反應，放在 Saturn 是防衛來源。(claims: western-function-element-templates-001)

元素不應直接回答「合不合」或「他會不會回來」。火象描述主動、直接與生命力；風象描述想法、溝通與社交連結；土象描述現實承接、穩定與責任；水象描述感受、同理與情緒理解。runtime 應把這些語義放回 point function，再由合盤壓力、修復與 timing 決定問題答案。(claims: western-function-element-templates-002, western-function-element-templates-003, western-function-element-templates-004, western-function-element-templates-005)

元素之間可形成支持或摩擦的背景，但它仍只是早期 comparison layer。Fire/Air 與 Earth/Water 可以提示節奏差異，不能升級成關係成敗判決。(claims: western-function-element-templates-006)

## in_relationship

穩定互動中，function element matrix 用來回答「需求用什麼材料表達」：火象需要直接熱度，土象需要可驗證穩定，風象需要對話與空間，水象需要情緒接住。它應幫使用者理解節奏，而不是貼人格標籤。(claims: western-function-element-templates-001, western-function-element-templates-002, western-function-element-templates-003, western-function-element-templates-004, western-function-element-templates-005)

### 優勢

- 能讓 Moon/Venus/Mars/Saturn 的需求語言比 generic sign text 更準確。(claims: western-function-element-templates-001)
- 能把元素比較降為風格與承接方式，不讓它壓過相位與現實互動。(claims: western-function-element-templates-006)

### 弱點

- 元素不能單獨判斷愛、不愛、承諾、聯絡或復合。(claims: western-function-element-templates-006)
- 元素是功能修飾層；沒有 point function 時不能獨立輸出人格結論。(claims: western-function-element-templates-001)

## in_breakup

分手、冷戰或斷聯情境中，元素矩陣主要用來拆「卡住時各自怎麼處理需求」。火象可能急著要直接反應，土象會回到現實安全，風象需要談清楚或拉開距離想，水象會先處理受傷與感受。這些都只能生成 conditional explanation，不能替對方保證行動。(claims: western-function-element-templates-002, western-function-element-templates-003, western-function-element-templates-004, western-function-element-templates-005, western-function-element-templates-006)
