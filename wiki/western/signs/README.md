# 西洋占星星座 KB 文章

12 星座，分四元素三模式：

火象（Fire）：Aries 牡羊、Leo 獅子、Sagittarius 射手
土象（Earth）：Taurus 金牛、Virgo 處女、Capricorn 摩羯
風象（Air）：Gemini 雙子、Libra 天秤、Aquarius 水瓶
水象（Water）：Cancer 巨蟹、Scorpio 天蠍、Pisces 雙魚

模式（Modality）：
- 開創（Cardinal）：Aries, Cancer, Libra, Capricorn
- 固定（Fixed）：Taurus, Leo, Scorpio, Aquarius
- 變動（Mutable）：Gemini, Virgo, Sagittarius, Pisces

⚠️ 注意：
不要寫成「太陽星座戀愛指南」這類膚淺內容。
星座本身較弱，要與行星結合才有意義。
V1 可以先寫元素特質（4 篇）+ 模式特質（3 篇），暫不為每個星座單獨建文章。
