# 合盤 pair-contact 句型模板

## core

Contact type 只能決定語氣，不能決定功能。Pair-contact 模板的任務是把「哪一對行星」和「conjunction/soft/hard」合成一句可控的 reducer language：同樣是 hard contact，Sun-Venus 要寫成好感混入自尊或期待落差；Moon-Mars 要寫成情緒與行動點火；Mercury-Jupiter 要寫成樂觀、說教或誇大承諾的風險。(claims: western-aspect-pair-contact-phrase-templates-001, western-aspect-pair-contact-phrase-templates-002, western-aspect-pair-contact-phrase-templates-004)

這些模板不是新增星盤事實。它們只把已計算的 pair family、contact type、orb、applying/separating 與 precision gate 翻成可審計的語氣，避免 LLM 把 soft 寫成保證、把 hard 寫成壞結果、把 conjunction 寫成命定。(claims: western-aspect-pair-contact-phrase-templates-005, western-aspect-pair-contact-phrase-templates-006, western-aspect-pair-contact-phrase-templates-007)

## in_relationship

仍在互動的關係中，pair-contact 模板應優先回答「這種互動會以什麼方式被感覺到」：

- Sun-Venus：被看見、欣賞、喜歡與期待。
- Moon-Mars：情緒被點燃、靠近變快、刺激也變快。
- Venus-Venus：喜歡語言、舒適感、validation 是否同頻。
- Mercury-Jupiter：能否把話拉開視角，或是否過度承諾。
- Moon-Moon：私密安全感、日常節奏與本能理解。
- Mars-Mars：行動節奏、推進方式與衝突速度。
- Mercury-Sun：理解、自尊、說服與被聽見。

### 優勢

- 讓同一 hard/soft/conjunction modifier 不會變成一套罐頭句。(claims: western-aspect-pair-contact-phrase-templates-001, western-aspect-pair-contact-phrase-templates-002)
- 讓 free page 的 technicalReading 更像真的讀到 pair family，而不是只讀到 broad contact type。(claims: western-aspect-pair-contact-phrase-templates-003, western-aspect-pair-contact-phrase-templates-004)

### 弱點

- Template 仍不能覆蓋實際 orb、precision gate、relationship context 或 timing climate。
- Template 不是完整 paid report；它只給免費頁的可控句型，不給完整修復策略。

## in_breakup

分手、冷戰或斷聯時，pair-contact 模板要避免兩個錯誤：一是把吸引寫成承諾，二是把壓力寫成無愛。安全寫法是把每個 pair-contact 翻成「還有什麼互動功能被觸發」和「哪裡不能誤認成機會」。例如 Venus-Venus soft 可以說喜歡語言仍有低壓入口，但不能說一定復合；Mars-Mars hard 可以說行動節奏容易硬碰硬，但不能把責任推給任何一方。(claims: western-aspect-pair-contact-phrase-templates-003, western-aspect-pair-contact-phrase-templates-006)
