# 相位功能組合 reducer

## core

相位 reducer 不能只說「有某某相位」。第一層要保留 pair family 與 contact type，第二層要讀到被觸發的行星功能、元素與三模式，第三層才進入使用者問題。這能把 reading 從「列相位」推進到「說明這個相位如何觸發這個人的需求語法」。

第一批組合 reducer 只處理 source 已足夠清楚的高頻關係問題：Mercury-Sun、Moon-Saturn、Venus-Saturn、Mars-Saturn。它們分別對應溝通/自尊、情緒/責任、愛意/阻滯、行動/煞車。這些都需要和 function element matrix、function modality matrix 一起讀，而不能單獨變成命運或復合判斷。(claims: western-aspect-function-combination-reducers-001, western-aspect-function-combination-reducers-002, western-aspect-function-combination-reducers-003, western-aspect-function-combination-reducers-004)

可見結果卡只應展示少數最能回答問題的 pivotal interaspects。這些卡片要說明「這個相位在關係中反覆觸發什麼功能」，而不是把所有已計算相位列成 technical dump。(claims: western-aspect-function-combination-reducers-005)

## in_relationship

關係仍有互動時，aspect-function combination 用來說明「哪個功能被哪種相位觸發」。Mercury-Sun hard 不是單純吵架，而是話語碰到自我感；Moon-Saturn hard 不是單純冷淡，而是情緒需求和實際建議語言不同；Venus-Saturn hard 不是沒有喜歡，而是喜歡被責任、害怕或控制議題壓住；Mars-Saturn hard 不是沒有欲望，而是推進和限制同時存在。

### 優勢

- 能把合盤相位與本命 function style 組合，讓閱讀更像真實個案，而不是 cookbook 條列。(claims: western-aspect-function-combination-reducers-001, western-aspect-function-combination-reducers-002)
- 能把 Saturn pressure 拆成情緒、愛意、行動三種不同卡點。(claims: western-aspect-function-combination-reducers-002, western-aspect-function-combination-reducers-003, western-aspect-function-combination-reducers-004)
- 能讓 when-to-contact 與 what-did-i-do-wrong 問題避免辯論、逼問或自責語氣。(claims: western-aspect-function-combination-reducers-001)
- 能讓關係契合度頁面只呈現最關鍵的合盤觸發，而不是弱相位清單。(claims: western-aspect-function-combination-reducers-005)

### 弱點

- 組合 reducer 仍然不是事件預測；它只說明被觸發的關係功能與互動風險。
- 不能因為看到 Saturn 組合就說對方不愛，也不能因為看到 commitment 語義就說等待一定值得。(claims: western-aspect-function-combination-reducers-003, western-aspect-function-combination-reducers-004)

## in_breakup

分手、冷戰或斷聯情境中，這一層最有用的是拆「為什麼有牽動但難以自然修復」。Mercury-Sun hard 要避免說服與糾正；Moon-Saturn hard 要翻譯安撫與責任；Venus-Saturn hard 要降低承諾壓力；Mars-Saturn hard 要避免油門和煞車同時踩。這些都只能生成條件式建議，不可寫成對方內心保證。(claims: western-aspect-function-combination-reducers-001, western-aspect-function-combination-reducers-002, western-aspect-function-combination-reducers-003, western-aspect-function-combination-reducers-004)
