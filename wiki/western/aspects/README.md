5 個主要相位（Major Aspects）：

- Conjunction 合相（0°）— 融合
- Opposition 對沖（180°）— 對立、互補
- Trine 三分相（120°）— 和諧
- Square 四分相（90°）— 緊張、推動
- Sextile 六分相（60°）— 機會

次要相位（V2 才考慮）：
- Quincunx 補十二分相（150°）
- Semisextile 半六分相（30°）

- 在合盤中的意義
- 容許度（orb）設定
