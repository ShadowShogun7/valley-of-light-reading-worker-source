# 西洋占星行星 KB 文章

10 顆行星：
- Sun（太陽）— 自我、生命力
- Moon（月亮）— 情緒、內在需求
- Mercury（水星）— 思考、溝通
- Venus（金星）— 愛、價值
- Mars（火星）— 行動、慾望
- Jupiter（木星）— 擴展、信念
- Saturn（土星）— 結構、考驗
- Uranus（天王星）— 突破、改變
- Neptune（海王星）— 夢、消融
- Pluto（冥王星）— 轉化、權力

每篇應包含 variants：
- core（行星本質）
- in_relationship（在關係中的角色）
- in_breakup（分手後此行星如何影響）
- in_general（人生整體中的角色）

主要來源：
- New Insights in Modern Astrology by Arroyo & Greene
- 後續加入：Saturn by Liz Greene 等

⚠️ V1 階段優先建立：Venus, Mars, Sun, Moon, Saturn
其他行星可以晚點處理。
