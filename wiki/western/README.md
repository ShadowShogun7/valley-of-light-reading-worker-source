# 西洋占星 KB 文章

西方現代心理占星學的結構化知識庫。

## 子目錄

- `planets/` — 10 顆行星
- `signs/` — 12 星座
- `houses/` — 12 宮位
- `aspects/` — 5 主要相位
- `synastry/` — 合盤分析（光之谷核心）
- `transits/` — 行運與 timing windows
- `precision/` — 出生時間、出生城市、Moon、Asc/Desc、houses 與 overlays 的精度護欄

## 建立優先順序

V0 source 已到位後：

1. synastry/ — 先建方法論與核心合盤相位（**最重要**）
2. aspects/ — 先建 Saturn pressure, Venus-Saturn, Moon-Saturn, Venus-Mars
3. transits/ — 只建 relationship timing windows，不做完整流年百科
4. planets/ — 再建 Venus, Mars, Sun, Moon, Saturn
5. precision/ — V0 必須先建出生資料精度與可展示限制
6. houses/ — 1, 5, 7, 8 宮
7. signs/ — 暫時只建元素特質與模式特質
