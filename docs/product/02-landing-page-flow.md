## 整體訊息策略

### 訊息層次（從上到下的情感旅程）

```
1. 情緒共鳴      —  「我懂你的痛」
2. 解方介紹      —  「命盤能看見你看不見的」
3. 方法論說明    —  「為什麼雙系統能看得更深」
4. 權威背書      —  「不是江湖術士，是研究院級數」
5. 產品階梯      —  「三個層次，依你的需求選擇」
6. 行動呼籲      —  「現在就看見答案」
```

### 文案核心原則

- **情緒先於理性** — 用戶帶著痛來，先共鳴後說服
- **具體優於抽象** — 用真實內心獨白，不用行銷話術
- **克制優於誇飾** — 不用「驚」「超」「100%」「保證」「絕對」
- **權威來自出處** — 用書名、學派、數據說話
- **不承諾結果** — 命盤是「看清」工具，不是「復合保證」

### 必須避免的字眼

```
❌ 「保證復合」「100% 準確」「絕對有效」
❌ 「神準」「超準」「不準免費」
❌ 「大師」「老師」「真人占卜」
❌ 「立即下單」「限時優惠」「錯過後悔」
❌ 「免費送你」「免費領取」
```

### 可使用的字眼

```
✅ 「看見」「看清」「真相」「方向」
✅ 「命盤」「合盤」「能量」「相位」
✅ 「光」「谷」「低谷」「轉折」
✅ 「依據」「出處」「研究院」「典籍」
```

### 四個階段卡片

  - 我現在能做什麼、不能做什麼

**階段 2：冷凍斷聯中（兩週 - 兩個月）**
- 副標：你最焦慮的時刻

  - 他現在心裡怎麼想

  - 我是還愛還是不甘心

**階段 4：還在一起但有危機**
- 副標：你最害怕的時刻
- 你需要看見的：
  - 我們關係的真正問題是什麼

```
沒有出生時間仍能完成 80% 的分析。
```
