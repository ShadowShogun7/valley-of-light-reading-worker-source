# 06 - Ritual System
## NT$2,480 復合儀式系統設計

> Legacy / future-product reference only.
> Current astrology V1 does not sell a ritual upsell or any in-result deep
> reading upsell. Use this only as historical context unless the product line is
> intentionally reopened.
> Active contract: `docs/product/00-current-v1-contract.md`.

> 光之谷 V1 的核心差異化之一。
> 沒有競品在做。對思雅型 ICP 用「現代正念」語言包裝後，是真正獨特的賣點。

---

## 為什麼儀式系統是強大的差異化

### 1. 沒有競品在做

- 塔羅占卜給答案
- 挽回課程給策略
- 心理諮商給支持
- **但沒有人提供「行動儀式」讓用戶感覺自己「在做點什麼」**

### 2. 符合台灣文化但不過度迷信

台灣人有拜月老、求姻緣的文化記憶。
但思雅型 ICP 不接受「太靈媒、太誇張」的版本。

**解法：用「現代正念儀式」語言包裝，視覺保持有質感。**

### 3. 變現空間大

實體儀式包：
- 成本約 NT$300
- 售價 NT$890（加購）
- 毛利約 NT$590

是高毛利商品，且包含在 NT$2,480 上層方案中可選加購。

### 4. 創造情感連結與留存

執行儀式的過程本身就是療癒。
無論最後結果如何，**用戶會記得「我為這段感情做過這些」**。
這個情感記憶讓用戶不會給負評。

## 四層儀式架構

每個用戶根據命盤分析會被推薦 2-3 種儀式（不是全部 4 種）。

```
┌──────────────────────────────────┐
│  第一層：能量淨化儀式               │ 給所有用戶
│  Energy Cleansing Ritual          │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│  第二層：自我復原儀式               │ 給渴望復合的用戶
│  Self-Restoration Ritual          │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│  第三層：關係連結儀式               │ 給命盤顯示有機會的用戶

└──────────────────────────────────┘

┌──────────────────────────────────┐

│  Release Ritual                   │
└──────────────────────────────────┘
```

## 第一層：能量淨化儀式

### 用途

清理過去關係的能量糾結。
**所有用戶都會被推薦這個儀式。**

### 適合時機

- 流月接近時
- 滿月後三天內
- 用戶情緒最重的那個下午

### 自備材料（免費版）

- 白蠟燭一根
- 海鹽一小撮
- 清水一杯
- 紙筆

### 儀式步驟（簡版）

1. **設定空間** — 找一個安靜的角落，關閉手機通知
2. **點燃白蠟燭** — 象徵新的開始
3. **書寫釋放** — 在紙上寫下你想要釋放的能量（具體事件、情緒、執著）
4. **海鹽淨化** — 將海鹽撒入清水，雙手輕輕清洗
5. **燃燒釋放** — 把寫的紙在燭火上點燃（注意安全）
6. **靜坐 7 分鐘** — 感受能量的轉換

### 實體儀式包版本

依命盤推薦寄送：
- 白色淨化蠟燭（特製，含薰衣草精油）
- 玫瑰岩鹽包（手工調配）
- 黑曜石小石（吸收負能量）
- 儀式手冊（精美印刷，含個人化內容）

### Narrative Framing（給思雅型 ICP）

❌ 不說：「淨化前世孽緣的法事」
✅ 改說：「現代正念儀式，幫你清理情感的視覺與情緒包袱」

❌ 不說：「驅邪除穢」
✅ 改說：「能量清理與心理重置」

## 第二層：自我復原儀式

### 用途

重建自己的能量場，提升自己的吸引力。
**給渴望復合的用戶 — 因為復合前先要「自己變好」。**

### 適合時機

- 個人流日吉日（系統會推薦）
- 連續執行 7 天效果最好

### 自備材料

- 粉色蠟燭
- 乾燥玫瑰花瓣
- 紙筆
- 鏡子

### 儀式步驟

1. **鏡前自我承諾** — 對著鏡子說出 3 件「我會為自己做的事」
2. **粉色蠟燭點燃** — 象徵自我之愛
3. **玫瑰花瓣撒落** — 在身體周圍撒花瓣
4. **書寫日記** — 寫下「我喜歡自己什麼」
5. **冥想 5 分鐘** — 感受自我之愛的能量

### 實體儀式包版本

- 粉色玫瑰蠟燭
- 乾燥玫瑰花瓣（手工烘乾）
- 自我承諾日記本（內含 21 天提示）
- 玫瑰精油小瓶

## 第三層：關係連結儀式

### 用途

在能量層面重新連結對方。
**給命盤顯示有機會的用戶。**

### 適合時機

- 流日吉時 + 雙方合盤金星時段
- 系統會推薦最佳日期

### 自備材料

- 紅蠟燭（兩根）
- 玫瑰水
- 雙方照片（或寫下對方代稱）
- 紅線

### 儀式步驟

1. **雙蠟燭點燃** — 一根代表你，一根代表他
2. **玫瑰水灑淨** — 在儀式空間周圍灑水
3. **紅線繫結** — 將兩根蠟燭用紅線連結（象徵性，不是綁緊）
4. **發送祝福** — 在心中默默向對方發送祝福（不是「請他回來」，是「祝他好」）
5. **靜默 10 分鐘** — 感受能量的連結

### 實體儀式包版本

- 雙蠟燭組（紅色，特製）
- 玫瑰精油與小噴瓶
- 連結符紙（純粹象徵，無宗教意涵）
- 紅線

### ⚠️ 重要 framing

絕對**不能**把這個儀式包裝成「招回前任」或「奪愛符咒」。

❌ 不說：「讓他回到你身邊的儀式」
✅ 改說：「在能量層面與對方和解、重新連結的正念練習」

❌ 不說：「用紅線綁住他的心」
✅ 改說：「象徵性地表達你願意重新連結的心意」

這個 framing 同時：
- 保護用戶不執著結果
- 保護品牌不被批評為「迷信」
- 符合思雅型 ICP 的審美

## 第四層：放下與祝福儀式

### 用途

真正放下，迎接新的可能。
**給命盤顯示緣分已盡的用戶 — 或自己準備好放下的用戶。**

### 適合時機

- 滿月
- 流月轉換日
- 重要紀念日（用戶選擇）

### 自備材料

- 黑蠟燭（一根）
- 一張舊物（與對方相關的小東西）
- 清水一盆
- 紙筆

### 儀式步驟

1. **黑蠟燭點燃** — 象徵告別
2. **書寫感謝信** — 寫一封信給對方，**主題是「謝謝」而不是「再見」**
3. **念出三句話** —
   - 「謝謝你陪我走過這段路」
   - 「我祝福你」
   - 「我也祝福我自己」
4. **舊物淨化** — 用清水輕輕擦拭舊物
5. **燃燒釋放** — 把感謝信燒掉（注意安全）
6. **靜坐 10 分鐘** — 感受新的可能

### 實體儀式包版本

- 黑色釋放蠟燭
- 釋放符紙（純象徵）
- 重生水晶（白水晶或月光石）
- 「謝謝」信紙組

### 為什麼這個儀式對品牌很重要

**它讓「沒希望」的命盤結果也有溫暖收尾。**

如果用戶花了 NT$2,480 但命盤顯示「應該放下」，
這個儀式給她一個尊嚴的告別方式。

**這也是退款率低的關鍵之一。**

## 實體儀式包設計

### 包裝規格

- 牛皮紙盒（環保感）
- 燙金 logo（質感）
- 黑色緞帶（沉穩）
- 不要：透明塑膠、亮色印刷、卡通圖案

### 內容物品質

- 蠟燭：100% 大豆蠟（環保）+ 精油（療癒香氣）
- 水晶：真的水晶（不是塑膠仿品）
- 符紙：手工和紙（不是廉價列印）
- 手冊：精美印刷（不是黑白影印）

**思雅型 ICP 一看就知道是有質感的東西。**

### 出貨時機

訂購後 3-5 天台灣本島送達。
不要超過 7 天 — 用戶會失去儀式的衝動感。

### 是否需要簽收

是 — 用宅配，不放超商。
原因：
1. 增加儀式感（「收到一個特別的包裹」）
2. 避免曝光（家人室友看到「開運物」可能尷尬）

## 儀式後 7 天能量追蹤

執行儀式後，系統每天推播：

### Day 1
```
今天是儀式後第一天。

你昨天執行的「能量淨化儀式」
正在你的能量場開始運作。

今天的能量觀察：
- 你可能會感到比平常輕一點
- 也可能感到有點空虛（這是正常的）

今天的建議：
不要主動聯絡他。讓昨天的儀式繼續發酵。
```

### Day 3
```
儀式後第三天。

你的命盤顯示，今天流日是甲午 —
這是「行動的能量」開始浮現的日子。

但等一下，行動不一定是聯絡他。
有時候，最好的行動是「為自己做一件好事」。

今天的建議：
做一件純粹為自己的事。買一杯好咖啡、去個喜歡的地方。
這是儀式效果的延伸。
```

### Day 7
```
儀式後第七天。

完整的一週過去了。

回想這 7 天，你會發現⋯⋯
（這裡 LLM 根據用戶實際情況生成個人化反思）

接下來：你可以考慮執行下一個推薦儀式 —
「自我復原儀式」。
```

### 追蹤機制

7 天結束後請用戶回饋：
- 「儀式對你有幫助嗎？」
- 「你有什麼感受？」

這些 feedback：
- 改善 KB 的儀式內容
- 提供未來行銷的見證（取得用戶同意後）

## ⚠️ 必須避免的事

### 1. 不要做「驅邪」「招魂」「分桃花」

這些都是民間信仰範疇，會嚇跑思雅型 ICP。

### 2. 不要承諾「執行儀式後對方一定會回來」

無論用戶問什麼，標準回答：
> 「儀式幫助你的能量場與內在狀態，不是控制對方的工具。」

### 3. 不要做「燒紙錢」「拜神像」這類視覺

實體儀式包的視覺必須是「現代 wellness」風格：
- 蠟燭、水晶、精油（OK）
- 神像、香爐、金紙（不要）

### 4. 不要過度頻繁推送儀式

每個儀式間至少間隔 5-7 天。
不要讓用戶覺得「我每天都在做儀式」。

### 5. 不要對「broke-up-recent」階段用戶推進階儀式

剛分手 2 週內只推「淨化」。
其他三個儀式等用戶情緒穩定後再說。
