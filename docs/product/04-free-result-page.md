# 04 - Free Result Page
## 免費結果頁設計（最關鍵的轉換點）

> Legacy reference only.
> Current astrology V1 has no free result page, no locked teaser rows, and no
> in-result upsell. Do not implement this document unless the product direction
> intentionally returns to a free funnel.
> Active contract: `docs/product/00-current-v1-contract.md`.

> 此頁面決定整個 funnel 的成敗。
> 用戶在這 60 秒內從「來看看好玩」變成「我必須付 NT$499 解鎖」。

---

## 設計目標

三件事必須同時達成：

1. **建立信任** — 讓用戶相信「這個系統真的懂我」
2. **創造好奇** — 讓用戶極度想知道「鎖住的內容到底寫什麼」
3. **降低決策成本** — 讓 NT$499 的決定看起來理所當然

### 核心心理學原理

**「具體就是可信」**

每個免費洞察必須讓用戶感覺「天啊這怎麼這麼準」。
這只能靠**真實的命盤計算 + KB 文章的具體解讀**。
如果免費內容是泛泛的「你們很合適但有挑戰」，用戶會立刻退出。

## V0 Free Answer Contract

免費結果不是把所有 KB 文章摘要出來。
它是一個 sharp diagnosis：

```text
user answers + chart calculation
    ↓
candidate signals
    ↓
slot selector
    ↓
4-6 selected primary signals
    ↓
free answer
```

Required free-result slots:
- `stage`：你們現在處在什麼關係階段
- `question`：直接回答用戶最想知道的問題
- `bazi_core`：最能支撐本次解讀的八字關係訊號
- `western_core`：最能支撐本次解讀的西洋關係訊號

Optional slots:
- `timing`：用戶問聯絡時機、復合機會、等待與放下時才加入
- `safety`：剛分手、自責、焦慮、危機狀態必須加入

Free output order:

```text
1. Direct answer
   2-3 句，先回答她問的問題，不先講命理背景。

2. Why this is showing up
   1 個八字訊號 + 1 個西洋訊號，具體但不堆術語。

3. What it means in this stage
   把訊號連回 cold-war / broke-up-recent / broke-up-long / crisis。

4. What to do next
   1 個具體行動，或 1 個不要做的警示。

5. Paid report preview
   預告完整報告會展開 timing、心理模式、衝突根源、可修復與不可修復之處。
```

Strategic rule:
- Free = core diagnosis.
- Paid = full map, timing, hidden pattern, and next-step strategy.
- Paid report must expand the same selected free signals so the upgrade feels continuous.

## SECTION A：契合度分數

### 視覺概念

大型圓形分數顯示。傳達「儀式感」與「結果感」。

### 內容範例

```
你們的命盤契合度

      ┌─────────┐
      │   72    │
      │  / 100  │
      └─────────┘

     深 度 連 結 型
   DEEP BOND TYPE

你們的命盤顯示，這不是一段平淡的關係 —
是命運曾經把兩個靈魂深深糾纏在一起，
現在正經歷一個重要的轉折點。
```

### 6 種關係類型

絕對不能讓任何用戶看到「沒有緣分」「應該放棄」。
即使最低分的命盤也包裝成「課題型」「成長型」。

| 分數 | 類型 | 框架 |
|------|------|------|
| 85+ | 靈魂共鳴型 | 強烈的命中連結 |
| 70-85 | 深度連結型 | 重要的緣分 |
| 55-70 | 課題成長型 | 透過挑戰成長 |
| 40-55 | 磨合考驗型 | 需要學習功課 |
| 25-40 | 課題完成中型 | 已學到大部分功課 |
| <25 | 已完成功課型 | 緣分圓滿告一段落 |

注意：原本的「緣分淺薄型」「課題結束型」改為更正向的「課題完成中型」「已完成功課型」— 對情緒脆弱用戶更友善。

### 為什麼用大圓圈

- 這是用戶**最想截圖分享的部分**
- 圓形 + 金色數字 + 類型標籤是完美的「IG 限動材料」
- 視覺重量足以讓用戶心理停留

**每張卡片都有一個「字」（如「丁」「乙」）：**

- 來自《滴天髓》，**真的有出處**
- 這是 KB 的價值體現

## SECTION C：三個免費洞察（核心）

V0 rendering can still show three cards, but the content source is now selector-first:
- Card 1 should contain the direct answer and stage meaning.
- Card 2 should expand `bazi_core`.
- Card 3 should expand `western_core`, plus timing/safety if selected.

### 設計原則

每個洞察必須做到三件事：

**1. 具體到讓用戶覺得「不可能猜得到」**
- ❌ 通用：「你們之間有強烈的吸引力」
- ✅ 具體：「乙木生丁火 — 他的溫柔天然滋養你的熱情」

**2. 解釋用戶內心的疑問**
- 洞察 1 解釋「為什麼放不下」
- 洞察 2 解釋「為什麼分手」
- 洞察 3 解釋「他現在到底怎麼了」

這三個問題是復合用戶 24 小時都在問自己的問題。

**3. 每個洞察底部有「出處」**
- 例：「— 出處：《滴天髓》論五行生剋第三章」
- 這個小細節讓整體權威感暴增 10 倍

### 洞察範例

**洞察 1：關於吸引力**

```
── 0 1 ──

為什麼你總覺得「沒有人能像他這樣懂我」

你們的日主關係是 乙木生丁火 — 他的溫柔（乙木）
天然滋養你的熱情（丁火）。乙木是花草之木，
有極強的順應性和感受力；丁火是燈燭之火，
需要被照顧才能持續燃燒。

在能量層面，他不需要努力就能感受到你需要什麼，
這也是為什麼即使分開了，你還是覺得
「沒有人能像他這樣讓我安心」。

這不是錯覺，這是真實的命理連結。

── 出處：《滴天髓》論五行生剋 第三章 ──
```

**洞察 2：關於分手原因**

```
── 0 2 ──

分手的真正原因，可能不是你以為的那個

你們的婚姻宮（日支）是 丑未沖 — 這代表你們在
「生活節奏」「重要決定」「金錢觀」上有本質性的對立。

丑是收斂保守的土，未是擴張慷慨的土；
同樣是土，但走向完全相反。

回想一下：你們最常吵的，是不是
「他想花你想存」「他想冒險你想穩定」
「他想隨性你想規劃」這類問題？

這不是誰對誰錯 — 是你們還沒學會
如何處理這種本質差異。

分手很可能不是因為不愛，
而是因為這個課題還沒學會。

── 出處：《八字合婚》第七章 日支婚姻宮論 ──
```

**洞察 3：關於對方現狀**

```
── 0 3 ──

他現在的狀態，跟你想的不一樣

他今年的流年走到 丙午年，正印當令 —
對乙木來說，正印是母親、是滋養、是「自我重建期」。

他現在的冷淡、不回訊息、看起來像放下了，
很有可能不是針對你 — 而是他正在面對自己人生中
一個需要獨處、反思、重新整理的階段。

這個階段對乙木日主來說特別煎熬，
因為他天生需要關係連結。

他不是不愛你，他是在面對自己。

── 出處：《子平真詮》論流年與用神 第十二章 ──
```

### 為什麼這三個洞察組合最有效

它們對應復合用戶內心**最深的三個疑問**：

1. **「為什麼我放不下？」** → 洞察 1 給出命理解釋（不是因為你軟弱）
2. **「為什麼會分手？」** → 洞察 2 給出原因（不是因為他不愛）
3. **「他現在在想什麼？」** → 洞察 3 給出狀態（不是真的離開了）

每個答案都是**「不是 X 的悲觀，而是 Y 的客觀」** 的框架。
這個框架讓用戶從「自我懷疑」轉到「我看到真相了」。

## SECTION D：鎖定內容（六個鉤子）

### 設計原則

**每個鎖定項 = 標題（極具誘惑）+ 預覽（戛然而止）**

```
🔒 他現在心裡到底還有沒有你？

從他的命盤可以看見「情感執著指數」，
他最近的流月顯示他⋯⋯
```

故意停在「他⋯⋯」這個位置，創造強烈的好奇 gap。

### 6 個鎖定項

```
🔒 他現在心裡到底還有沒有你？
從他的命盤可以看見「情感執著指數」，
他最近的流月顯示他⋯⋯

🔒 2026 年你們的最佳復合時機
未來三個月的能量流動 · 哪一旬聯絡壓力比較低 ·
哪些日子千萬不要主動⋯⋯

🔒 你該做和不該做的 5 件事
基於你們合盤刑沖關係的個人化策略 ·
避免觸發那個讓他抗拒的模式⋯⋯

🔒 中西命理雙重確認的命運訊號
當八字和星盤同時指向同一件事 ·
這是最值得相信的訊息⋯⋯

🔒 你的盲點 — 不改的話復合也會再分
從你的本命盤可以看見，
你在感情中反覆出現的那個模式⋯⋯

🔒 他真正需要的，跟你以為的不同
乙木日主在感情中需要的東西，
跟你的直覺判斷有 90% 的誤差⋯⋯
```

### 為什麼是 6 個

不能少於 5（顯得不夠豐富），不能多於 7（資訊過載）。

**這 6 個鉤子涵蓋用戶最焦慮的問題：**
1. 他還愛我嗎（情感執著）
2. 我什麼時候該行動（時機）
3. 我該做什麼（策略）
4. 哪個答案是真的（雙系統確認）
5. 我有什麼問題（自我盲點）
6. 他要什麼（對方需求）

## SECTION E：NT$499 CTA

### 視覺概念

突出但不浮誇。傳達「值得，但不貴」。

### 內容

```
🔓 解鎖完整命盤報告

不只是分析 · 是為你量身定做的方向
一次解鎖，永久查看

NT$ 499

— 完整八字合盤深度分析
— 完整西洋合盤分析
— 中西交叉雙重確認分析
— 2026 全年流年關係預測
— 個人化挽回策略建議
— 5 次「問光之谷」AI 深度問答

[ 解 鎖 完 整 報 告 → ]

已有 8,247 人解鎖完整報告
```

### 設計細節

**為什麼不用「✓ 打勾」而用「— 破折號」？**
- 打勾太商業感
- 破折號更克制、更有品質
- 符合「研究院級」品牌調性

**為什麼「8,247 人」？**
- 具體數字 > 整數
- 「12,000+」太假，「8,247」感覺真實
- 但不能太低（避免「沒人買」印象）

**為什麼「一杯飲料的價格」不寫了？**
- 之前的草稿曾寫「一杯飲料的價格」
- 但這個 framing 對思雅型 ICP 偏便宜感
- 改成「不只是分析・是為你量身定做的方向」更有品質

## 個人化規則

結果頁的內容必須根據用戶 Step 3-5 的回答**動態調整**：

### 根據階段（Step 3 Q1）

- **broke-up-recent**：洞察 3 強調「先照顧自己」，鎖定項不推「最佳聯絡時機」（怕用戶衝動）
- **cold-war**：標準版（這是核心 ICP 階段）
- **broke-up-long**：洞察 3 改為「你是還愛還是不甘心」
- **crisis**：完全不同的解讀框架（不是復合，是修復）

### 根據主要問題（Step 5）

選的問題出現在報告封面：
```
給你 — 關於「他現在心裡還有我嗎」這個問題
```

並且讓對應的洞察更深入。

### 根據是否有出生時間

- 有：分析包含上升星座、宮位、八字時柱
- 無：分析省略上述，註明「知道時間後可更精準」

## 失敗情境的處理

### 命盤指向「沒緣分」

絕對不直接說。改用：

❌「你們沒有緣分，建議放下」
✅「你們的關係已經完成了它的使命，命盤顯示新的可能正在出現」

### 命盤無解（極端罕見）

如果計算錯誤或資料不完整：
- 顯示「正在優化你的分析」
- 後台通知開發者
- 不要顯示空白頁面

### 用戶情緒崩潰（從 Step 3 推斷）

如果階段是 broke-up-recent + 主要問題是「我該繼續等還是放下」：
- 這代表用戶可能處於極度脆弱狀態
- 結果頁加入額外的關懷提示
- 不主動推 NT$2,480 升級

每天追蹤：
- 完成免費分析的用戶數
- 看完所有 section 的用戶數（捲動到 SECTION F）

- 生成分享卡片的用戶數

**核心轉換指標：完成分析 → 付款 ≥ 12%**

- 三個免費洞察是否夠具體
- 鎖定項是否創造足夠好奇
- CTA 文案是否需要優化
- 價格呈現是否清楚
