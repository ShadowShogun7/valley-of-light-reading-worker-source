# Valley of Light brand assets

Use these files through `src/components/BrandLogo.tsx` so sizing, accessibility,
and asset selection stay consistent.

- `valley-of-light-mark.webp`: compact icon, favicon, or square brand slot.
- `valley-of-light-horizontal.webp`: primary full logo for landing and result surfaces.
- `valley-of-light-stacked.webp`: tall layouts with generous vertical space.
- `valley-of-light-wordmark.webp`: compact horizontal headers where the icon is already present.

Do not redraw the logo in CSS, replace it with a text approximation, or apply a
color filter to these files.
