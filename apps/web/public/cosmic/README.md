# Cosmic Visual Assets

These bitmap assets are generated for Valley of Light and do not copy the reference artwork.

They are production-safe placeholders for the immersive paid-result dashboard:

- `galaxy-nebula.webp` is the full-scene cosmic background.
- `planet-*.png` files are generated surface maps for the Western V1 runtime points currently exposed by the paid result model.
- `planet-sun.png` supports the central chart light source; it is decorative context, not an extra natal point.
- `planet-earthlike.png` is used for the relationship angle/body marker where the V1 runtime exposes `Desc`.
- `sun-mandala.png` is the ornamental solar medallion behind the central chart sun.
- `zodiac-glyph-wheel.png` is the generated 12-sign astrological instrument layer for the Three.js orbit plane.
- `saturn-ring.png` supplies the transparent ring map for Saturn.
- `sun-corona.png`, `star-sprite.png`, `aura-gold.png`, and `aura-blue.png` support the Three.js glow and particle layers.
- `solar-system-scope-*.webp` files are WebP runtime copies converted from Solar System Scope textures for Sun, Moon, Mercury, Venus atmosphere, Mars, Saturn, and Earth/Desc.
